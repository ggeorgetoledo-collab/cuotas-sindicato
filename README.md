# Cuotas Sindicales

Registro de pagos de cuotas sindicales y portal de socios (QR + PIN).

- App dirigentes: https://ggeorgetoledo-collab.github.io/cuotas-sindicato/cuotas.html
- Portal socios: https://ggeorgetoledo-collab.github.io/cuotas-sindicato/portal.html

Los datos se guardan cifrados (datos-*.enc.json, portal-*.json).
